# Public aggregate benchmark facts

human_summary_endpoints.csv contains five manually verified NCA summary facts,
not individual participant records or a copied article/figure. Source table locators,
registered trial IDs, units, arm-level covariate descriptors and endpoint denominators
are in the file. Calibration/validation trials are disjoint; endpoints within an
arm are correlated. Individual identities and covariance were not acquired.

Sources: Li et al., DOI 10.1016/j.curtheres.2026.100848, Table 4 observed Healthy SD R;
Hillson et al., DOI 10.1002/prp2.380, Table 2 US Humira. The latter article displays
CC BY-NC-ND 4.0; article text/figures are not redistributed here. Rights for source
reuse should be checked before redistribution beyond these attributed factual
summaries. Source URLs and archived retrieval hashes are retained in metadata.
The benchmark CSV hash is checked before numerical use.

The 7E3 source snapshot is obtained separately from an immutable public OSP commit;
its model code states GPLv2. Its underlying measurement/report rights are separately
noted. This benchmark requires no private patient data and does not support human
tissue validation.
